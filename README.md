# VectoNMT

Україномовна платформа для підготовки до НМТ: практика за темами, повна симуляція іспиту, автоматична перевірка відповідей і персональна статистика.

**Сайт:** [nmt-focus.zzaydik.chatgpt.site](https://nmt-focus.zzaydik.chatgpt.site/)

## Можливості

- практика з української мови, математики, історії України, англійської та німецької мов, біології й географії;
- вибір теми та кількості завдань;
- випадкове формування тестів без участі AI;
- два етапи симуляції НМТ із навігацією між предметами й завданнями;
- необов’язкова перерва до 20 хвилин між етапами;
- перевірка відповідей, пояснення помилок і переведення тестового бала у шкалу 100–200;
- збереження прогресу, серії занять та історії результатів;
- окрема база запитань, підключена до платформи.

## Архітектура

- Next.js / Vinext і React;
- Cloudflare Worker;
- Cloudflare D1 та Drizzle;
- база й правила тестування працюють автономно, без генерації запитань під час проходження тесту.

Структура платформи та формат даних описані в [docs/PLATFORM.md](docs/PLATFORM.md).

## Локальний запуск

Потрібен Node.js 22.13 або новіший.

```sh
npm run install:ci
npm run build
for migration in drizzle/*.sql; do
  node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file "$migration"
done
npm start
```

Після запуску платформа буде доступна за адресою, яку покаже локальний сервер.

## Перевірка

```sh
npm run test:scoring
npm run test:platform
```

Тест платформи запускається разом із локальним сервером і перевіряє практику, симуляцію, таймери, необов’язкову перерву, підрахунок балів та статистику.
